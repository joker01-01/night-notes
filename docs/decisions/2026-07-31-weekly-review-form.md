# 决策记录 002：周场形态（2026-07-31）

> 状态：已接受 · 来源：grill-me 设计拷问会话（第一性原理推演） · 关联：PRODUCT.md §1 / §3 / §6 修订

## 背景

发布路线定案后，周场作为北极星（周场完成率）的核心载体，其具体形态需要确认。
输入材料：用户日常痕迹（自由写 / 日收束）+ 上周总结（周问 + 回答 + next_focus）。
约束：PRODUCT.md 宪法——打开优先、当时感不可事后补全、具体胜过正确、时间要有箭头、非考官审讯。

## 第一性原理

1. 人的长期记忆对「感受/分量」保真度极低——失真的是当时感，不是事件。
2. 周复盘的存在理由 = 在痕迹仍热时提取「本周最重的一件」并固化其分量，让信号指向下一步。
3. 三个动作：回忆（AI 可代劳）、识别（只有用户知道哪件重）、言说（必须是用户自己的话）。
4. AI 的改善方向：把复盘压到最小可完成单元——5 次点选 + 1 句自己的话，而不是替用户做复盘。

## 形态空间与裁决

| # | 形态 | 裁决 |
|---|------|------|
| 1 | 纯自由书写 | 否：解决不了「从零组织问题」，无周问即无核心资产 |
| 2 | 固定模板多问 | 否：与废案四问同构，压迫感 |
| 3 | 纯 AI 单问 | 否：日痕迹薄时问得泛 |
| 4 | 热身给料 + AI 单问 | 演进为 4′ |
| 4′ | **用户自选一件 + AI 就它问感受（采纳）** | 选择权在用户，问得准 |
| 5 | AI 导览 + 用户自选 | 被 4′ 吸收（自选即导览） |
| 6 | 多轮对话 | 否：拖长，打击完成率 |
| 7 | AI 周报先行 + 用户校对 | 否：一键大周报废案 |

## 主路径（硬）

AI 记忆管家（痕迹聚类候选 + 上周承接对照）→ 用户自选本周最重一件（可自加）→ 点选情绪表情（6-8 个预选，可「说不清/跳过」）→ AI 生成一个温柔周问（只问感受/分量）→ 用户一句话作答（可语音）→ AI 收束草稿（echo + 2-3 个 next_focus 候选）→ 用户点选/改写确认。

## 关键决策

| 分支 | 决策 | 理由 |
|------|------|------|
| 选择化 | 「写累选易」：除作答外全部为点选 | 认知成本低一个数量级；直接服务北极星 |
| AI 分工 | 记忆管家 / 感受主人：AI 只做检索 / 对照 / 出题 / 收束草稿；**永不代写回答、永不先出总结** | 言说环节代笔则当时感失真（第一性链条断裂）；AI 概览抢先于用户反思，会压制自己的感受 |
| 情绪表情 | 单表情，预选集 6-8 个；不设分量滑杆 | 一个控件就好；分量从回答里长出来，不被滑杆预消耗 |
| 上周信号 | 承接式：问「分量变没变」，不问「做了没」；验证只做 AI 隐形上下文 | 验证式是考勤机 / 愧疚引擎；承接式保持感受框架且自然包含隐式验证 |
| 提纲热身 | 退役（三个空格被「自选一件」取代） | 不再出现在主路径 |
| 完成口径 | 留下「周问 + 回答」即完成；点选 / 表情 / 收束不计入 | 北极星口径不变 |
