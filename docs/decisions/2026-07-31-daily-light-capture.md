# 决策记录 003：日轨极轻记（2026-07-31）

> 状态：已接受 · 来源：grill-me 设计拷问会话（「写累选易」延伸至日轨） · 关联：PRODUCT.md §1 / §3 / §4 / §6 修订

## 背景

周场选择化后，「写累选易」延伸至日轨。日轨的第一性：**捕获与连续**，唯一消费者是周场（日为周服务）；要防的是「不敢打开」。对「今晚没话想说」的人，一个表情的成本远低于五个字。

## 决策

| 分支 | 决策 | 理由 |
|------|------|------|
| 极轻记 | 日场新增可选「表情 ± 一句话」入口；表情复用周场 8 个 + 跳过 | 写累选易；没话写也留下痕迹 |
| 痕迹口径 | 只有表情也计入痕迹（今晚成立 = 正文文字 或 表情） | 情绪本身就是有方向的痕迹；打开优先 |
| 数据模型 | `daily_sessions.emotion TEXT DEFAULT ''`；一句话写入现有正文槽 | 改动最小；自由书写 + 表情可并存；回看/聚合顺 |
| AI 边界 | 只有表情（无文字）时隐藏「再问自己一句」和「收一收」 | AI 需要文字材料；表情不触发 AI |
| 宪法红线 | 极轻记是可选入口，自由书写仍是主路径；绝不变成每日必答门禁 | 每日四问幽灵不得借壳复活 |

## 周场联动

- 只有表情的天在周场痕迹块显示为「YYYY-MM-DD · 😣（只有情绪，无文字）」。
- 周问 prompt 增补（已写入决策记录 002）：对「只有情绪、无文字」的天，可用情绪走向提问，但不得编造具体事件。

## 数据模型变更

- `daily_sessions.emotion TEXT DEFAULT ''`（Flutter Drift schema 落地；原型冻结不改）。
