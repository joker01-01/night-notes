# 两周核心闭环验证

这是一份给试用用户的最小说明。目标不是收集“喜欢不喜欢”，而是观察用户是否愿意完成第二次周场。

## 使用路径

1. 第一天打开「今晚」，写几句或直接完成一次极轻记录。
2. 周场有日痕迹后，点击「问自己一句（本周）」并写下自己的回答。
3. 如果还没有日痕迹，在「本周」的起步模式里填一件最近最想搞清楚的事。
4. 下一周再次打开「本周」，观察问题是否承接了上周的回答或下一步。

## 每次只记录四件事

- 今天是否留下了痕迹：是 / 否
- 本周是否留下了“周问 + 回答”：是 / 否
- 周问是否具体地问到了在意的事：1～5 分
- 下周是否愿意再打开：是 / 否

## 第二周访谈

请用户用自己的话回答：

1. 哪一次周问让你停下来想了一下？
2. 上周回答被承接时，你觉得是“记得我”还是“只是换了模板”？
3. 哪一步最容易让你不想继续？
4. 如果只能保留一个功能，你会留下什么？

## 结果记录

建议按匿名编号记录，不收集 API Key 或日记原文。至少完成 10 位用户的两周观察后，再决定是否进入 Flutter 重写。
