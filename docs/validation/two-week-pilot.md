# 夜记｜两周核心闭环验证

这是一份给试用用户和记录人的最小说明。目标不是收集“喜欢不喜欢”，而是观察用户是否愿意完成第二次周场。

试用范围：10～15 位符合目标画像的朋友，连续两周。目标画像是正在独立推进项目、创作、转型或重要选择，并且偶尔感到卡住、摇摆或方向模糊的人。

## 给试用用户的说明

这不是每日打卡，也不是心理咨询。平时想写就留一点；每周找一次时间，问自己一句。AI 只在你主动进入周场时使用你选定的相关内容。你可以随时跳过、退出或删除记录。

## 使用路径

1. 第一天打开「今晚」，写一句、点一个情绪，或直接选择「先这样」。
2. 日常记录可以在任何时间发生；只有情绪、没有文字也算一次痕迹，但不会触发 AI。
3. 周日在「本周」看到邀请后，选择一个候选主题；也可以直接填一件最近最想搞清楚的事。
4. 选择情绪或跳过，回答 AI 的一个周问，再写下自己的回答。
5. 查看短回声和可选下一步；下一步可以修改、跳过或留空。
6. 下一周再次打开「本周」，观察问题是否承接了上周的回答或下一步。错过推荐时间也不需要补作业。

## 每次只记录五件事

- 今天是否留下了痕迹：是 / 否
- 本周是否留下了“周问 + 回答”：是 / 否
- 周问是否问到了在意的事：问到了 / 有点接近 / 太泛
- 下周是否愿意再打开：是 / 否
- 哪一步让你想退出、感到压力或觉得多余：自由填写

默认只记录匿名编号和以上结构化反馈，不收集日记原文、API Key 或完整截图。用户主动分享的内容另行征得同意。

## 第二周访谈

请用户用自己的话回答：

1. 哪一次周问让你停下来想了一下？
2. 上周回答被承接时，你觉得是“记得我”还是“只是换了模板”？
3. 这次校准有没有帮你看清一件事，或改变你对下一步的判断？
4. 哪一步最容易让你不想继续？
5. 如果只能保留一个功能，你会留下什么？

## 试用成功标准

- 至少 60% 的参与者完成第一次“周问 + 回答”。
- 完成第一次的人中，至少一半第二周再次打开。
- 至少 5 人明确说出产品帮助自己看清了一件事，而不只是“AI 问得不错”。
- 没有严重的隐私、打扰或压力反馈。

如果未达到标准，优先修改周问质量、启动门槛和承接方式，不优先增加功能。
