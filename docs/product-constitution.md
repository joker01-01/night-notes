# 夜记｜产品形态冻结 v0.1

更新时间：2026-08-12
适用范围：首轮 10～15 人、连续两周的朋友试用

## 一句话

**夜记是给独立工作者、创作者和长期自己做决定的人使用的低压力自我校准工具。**

对外表达：**随手记一点，每周问自己一句。**

## 核心闭环

1. 用户随时留下一个念头，或只点一个情绪。
2. 到推荐的周场时间，AI 提炼 2～3 个可能值得谈的线索。
3. 用户选择一件事，也可以自己写主题。
4. 用户可选一个情绪，或跳过。
5. AI 只问一个具体、温和的问题。
6. 用户用自己的话回答；这条回答是周场的核心资产。
7. AI 生成一句短回声和一个可修改、可跳过的下一步。
8. 下周只承接用户自己的周问、回答和下一步，不生成长篇周报。

## 硬边界

- 不要求每天记录，不做连续打卡，不设逾期惩罚。
- 晚上是主要入口，但白天可以快速留下痕迹。
- 只有情绪、没有文字的记录也算完成，但不触发 AI。
- 周场推荐周日或周一，但没有截止时间；用户错过后仍可随时完成。
- 每周默认一问一答；只有用户主动要求才继续深入。
- AI 不代写回答、不替用户下结论、不做诊断或治疗。
- 用户可以修改、删除、导出自己的原文和 AI 产物。
- AI 只使用当前周材料和有限的上周承接；使用了什么内容必须可见、可排除。

## AI 与隐私

- 日常记录默认不触发 AI。
- 首轮封闭试用可使用产品方提供的模型通道，但必须事先告知并获得同意。
- 试用阶段不要求用户申请 API Key；正式产品再做 BYOK、应用锁和更强的本地加密。
- 模型请求只发送本次周场所需上下文，不保存日记原文作为研究数据。

## MVP 只验证什么

- 今晚：一句话 / 一个情绪 / 先这样。
- 本周：候选 → 自选主题 → 情绪 → 一个周问 → 用户回答 → 短回声。
- 回看：原话、周问、回答、上周承接。
- 一次可关闭的本地周提醒。

暂不做：语音、复杂趋势图、账号与同步、BYOK、全能 AI 聊天、长篇自动总结、任务管理和社交功能。

## 试用成功标准

- 10～15 人参与。
- 至少 60% 完成第一次“周问 + 回答”。
- 完成第一次的人中，至少一半第二周再次打开。
- 至少 5 人明确说出产品帮助自己看清了一件事，而不只是“AI 问得不错”。
- 默认只收集匿名行为与反馈，不收集日记原文、API Key 或完整截图。

## 调性

安静、现代、清醒、可退出。
温和但不讨好，具体但不武断。
视觉避免复古日记本、心理咨询室和通用 AI 模板审美。
