# 夜记｜试用说明

## 概要

夜记是一个给自己用的轻量自我校准工具：随手记一点，每周问自己一句。

它不是每日打卡，也不是心理咨询。你不需要每天记录，也没有逾期、补作业或完成压力。

本次是小范围 Android 试用，主要想看看：它能不能帮助你在一周之后，更清楚地看见一件自己正在经历的事。

## 怎么开始

1. 安装并打开「夜记」。
2. 进入「今晚」，写下一句话，或者只选择一个此刻的情绪。
3. 如果暂时不想写，也可以直接离开；不需要为了完成而记录。

第一次使用不需要注册账号，也不需要填写任何个人资料。

## 三个主要入口

### 今晚

这里不是日记作业，只需要留下今天最想记住的一点。

你可以：

- 写一句话或几句话；
- 只选择一个情绪，留下一个轻量痕迹；
- 写完后直接点「留下这一点」；
- 如果想继续想一想，再点「问自己一句」。

只有你主动点击 AI 相关按钮时，才会尝试联网。只选择情绪而没有写文字时，不会触发 AI。

### 本周

推荐在周日或周一打开，但没有截止时间，什么时候完成都可以。

使用路径是：

1. 从候选主题中选择一件最近比较占心力的事；
2. 也可以自己写下一个主题；
3. 选择这周的感觉，也可以跳过；
4. 让夜记问自己一句；
5. 用自己的话回答；
6. 查看最后的短回声和可选的下一步。

这里最重要的不是 AI 的回答，而是你自己的那段回答。

### 历史

这里可以回看之前留下的每日记录和每周回答。

它更像一个安静的存放处，不要求你整理成总结，也不要求你马上得出结论。

## AI Key 要不要填写

到时候试用我发给你的 API_Key 就可以。

没有 API Key，夜记会使用本地准备好的问题和收束方式；填写 DeepSeek API Key 后，今晚和本周的相关按钮可以尝试使用 AI 生成更贴合当前内容的问题。

填写方式：

1. 进入「设置」；
2. 填写自己的 DeepSeek API Key；
3. 点击「保存设置」。

Key 只保存在这台手机。请不要我发你的 Key 发到别的地方。

## 数据和隐私

- 目前不需要账号登录。
- 记录默认保存在这台手机上。
- 只有你主动点击 AI 相关按钮时，当前操作所需的内容才会发送给对应的 AI 服务。
- 不会因为你没有每天记录而提醒、催促或惩罚你。
- 请不要在试用反馈中直接发送完整日记、API Key 或包含隐私内容的截图。

## 这次试用暂时没有什么

当前版本暂不提供：

- 账号和云同步；
- 自动提醒；
- 导入导出；
- 多设备同步；
- 社交、分享和打卡排行。

## 希望你怎么试

不用刻意每天使用。建议至少经历一次完整的「本周」流程：

- 第一周：随手留下几次记录，然后完成一次「周问 + 回答」；
- 第二周：再打开一次「本周」，看看它是否接得住你上周留下的内容。

每次使用后，可以简单告诉我：

1. 哪一次问题让你真的停下来想了一下？
2. 哪一步最容易让你想退出？
3. 你会不会愿意下周再打开？
4. 如果只能保留一个功能，你会保留什么？

不用评价得很完整，一两句话就够。说“不想用”“太长了”“问题太泛”同样有帮助。

## 试用提醒

夜记只做自我反思与方向校准，不替你诊断、治疗或作决定。如果某段内容让你感到明显不适，可以随时停止使用，也不需要向我解释原因。

感谢你愿意帮我试用这个还在变好的小工具。
